# Croki features and value

`FIRM-SPEC.md` owns product physics; `STATE.md` owns proof.

## Value order

1. Move across Product and GTM with exceptional speed.
2. Let Claude, Codex, and specialists do ambitious, creative, exact work.
3. Pursue several approaches without losing coherence.
4. Let market reality change the Product immediately.
5. Make every cycle improve the next one.
6. Retain founder authority over current truth and every world crossing.

## Capability to consequence

| Capability | Founder consequence |
|---|---|
| Direct Claude/Codex Work | The founder gets native agent capability, exact code/material, and rapid steering without an intermediary persona. |
| Durable Threads, Runs, and isolated attempts | Several approaches can move at once without losing origin, cost, artifacts, session, or comparison. |
| Living Product/GTM canvas | Product dependencies, motions, work, outward actions, and evidence remain coherent across a broad portfolio. |
| Durable provisional model branches | Agents can explore substantial Product changes without silently changing current truth or losing alternatives. |
| Selective founder merge | The founder adopts only justified changes and resolves current-truth drift explicitly. |
| Direction-scoped continuing work | Safe inward work can survive restart and relevant evidence without workflow configuration or unrelated autonomy. |
| Generic outward actions | Releases, interviews, messages, onboarding, partner work, spend, and bespoke delivery keep their real identity and exact authority. |
| Source-bearing evidence return | Reality changes the exact Product or GTM claims it supports rather than becoming dashboard noise. |
| Unscalable work as first-class | The founder can learn through manual, bespoke, or unusual action before repeatability exists. |

## Primary user

A technical founder who already builds with frontier agents and whose constraint is no longer producing work. The
constraint is changing a venture fast across Product and market while keeping truth, context, judgment, and many
simultaneous approaches coherent.

## Defensible advantage

Croki compounds local venture context, exact execution history, evidence, provisional alternatives, and founder
decisions into lower coordination cost and improving next-move speed. The moat is not a fixed workflow. It is the
rate at which useful reality becomes coherent Product and GTM action.
