# Prove owner-hosted multiplayer before managed cloud

The first multiplayer Croki runs in one owner-controlled Execution Environment reached directly, through SSH or a private network, or later through a Croki-managed relay used only for transport. Managed persistent cloud environments remain a separate expansion gated by repeated collaboration value, remote-access pain, retained use, and paid demand. Croki will not delay the multiplayer behavior behind cloud provisioning, tenancy, billing, and uptime obligations.
