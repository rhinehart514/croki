# Projects share; Threads hold the work

A Project is Croki's collaboration boundary, while each existing Thread is the canonical shared object for one intended outcome. Croki will not add a Room, collaboration mode, or second team workspace: a solo Project uses the same model with one current member, and multiplayer presence appears only when another person is relevant. This preserves Croki's existing Thread-centered product while making shared work inherent rather than bolted on.
