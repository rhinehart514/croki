# Release market-return surface

## Judgment

Releases is the founder's market-return surface. Before it exposes configuration or record detail, it answers:

1. What is moving into the market?
2. What did reality return?
3. What judgment or authority still needs the founder?

The prior stacked record projection contradicted the canonical release model and obscured this value. The selected composition is a full-width causal canvas with a contextual inspector.

## Screens touched

- Product / GTM → Releases empty state
- contextual release seed before canonical creation
- canonical draft, in-market, needs-you, and ended release states
- release step inspector, founder gate, bounded observation, and joined trace

## Hierarchy and interaction

- The header names the exact release and its current situation: preparing, needs you, waiting for evidence, or returned evidence.
- The center is the five-node causal spine: Product delta → Customer consequence → Distribution → Outward action → Evidence.
- Evidence visibly returns to Product. A solid edge means attributable evidence exists; an open dashed return preserves the unclosed loop.
- Selecting one node opens only its exact joins, missing connection, agent action, and founder control.
- Founder gates stay attached to Outward action. Observation authority stays attached to Evidence. Joined work and receipts live behind Trace.
- Empty Releases starts from exact Product / GTM truth; it does not open a blank form.

## Craft

- Existing Drover tokens and primitives remain authoritative: near-black ground, quiet panel, amber founder authority, blue active manipulation, DM Sans hierarchy, JetBrains Mono state/provenance.
- Existing `@xyflow/react` canvas primitives are reused; no package or parallel interaction system was added.
- Motion is limited to selection and edge feedback, with reduced-motion coverage.
- The signature element is the evidence-return edge, which makes Drover's evidence-returning product thesis legible without explanation.
