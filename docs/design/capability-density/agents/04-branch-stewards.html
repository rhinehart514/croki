Agent model

Every agent inhabits a future.

An agent is created by a meaningful fork. It owns the internal coherence of that possible venture and disappears when its branch is killed or merged.

  • IdentityThe branch and its governing thesis.
  • MemoryEverything that happened within that future.
  • AccountabilityHow well the branch survives contact with reality.
First proof: several agents produce working venture variants, a returned outcome selects one, and the winner merges without preserving a synthetic employee roster.
