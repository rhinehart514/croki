## Prototype

This reversible prototype tests a single spatial world where venture intent, product value, reusable GTM systems, motions, campaigns, bets, exact releases, and returned outcomes remain connected. It is not a production route and has no backend.

Serve from the repository root:

```sh
python3 -m http.server 4178
```

Then open `http://127.0.0.1:4178/docs/design/venture-architecture-adaptation/`.

Keyboard:

- `N`: add an open, untyped concept.
- `1`–`5`: venture, architecture, motion, campaign, and bet altitudes.
- `O`: deterministic outline.
- `Escape`: broaden one level.
- `Command/Ctrl+Enter`: send the current prototype direction.

The Buffalo Projects fixture proves open founder-defined material, promotion into an operational role, shared systems, a campaign within a motion, an exact wall-held release, and an evidence-supported return. DenialShield proves the same model on a materially different dental revenue venture. “How it runs” reveals teammates, runtime, worktree, cost, and authority only after inspection.
