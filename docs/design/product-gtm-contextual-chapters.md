# Product / GTM contextual chapters

## Outcome

Product / GTM opens on the nearest exact causal chapter instead of treating the longest graph path as the
founder's current priority. The projection remains one complete venture canvas and changes presentation only;
it never changes relationships, authority, placement semantics, or canonical Product truth.

## Hierarchy

The opening frame resolves in this order:

1. an explicitly selected Product/GTM object or exact attached work, branch, action, or evidence;
2. an outward action waiting for founder authority;
3. unread returned evidence;
4. failed, completed, or decision-bearing exact work that needs review;
5. a provisional branch whose base Product truth has moved;
6. active exact work;
7. the whole-venture causal trunk.

The focused object's strongest bounded upstream and downstream path becomes the contextual spine. Its immediate
causal neighborhood remains fully legible; unrelated material stays spatially present but quiet. The initial
camera frames only the focal object, one upstream dependency, up to two downstream consequences, and its exact
attached work/action so the chapter remains readable at supported desktop sizes.

## Interaction

- Entering from Work uses the existing direct object/Thread reference; no router or context stack was added.
- Selecting a node recomposes its causal chapter and expands exact material in place.
- `Whole venture` clears the temporary chapter and restores the broad canvas without creating a mode.
- A founder-chosen whole-venture view remains local presentation state and is reset by selecting another node.
- Returned evidence is promoted only while its linked work is unread; reviewed evidence earns no permanent
  attention chrome.
- Off-path relationship labels stay silent. Labels remain on the causal spine and on focused provisional or
  territory-crossing relationships.

## Visual contract

The existing near-black room, DM Sans operating type, JetBrains Mono exact material, blue focus, amber authority,
meaning-bearing node silhouettes, territory-crossing spectrum, and in-place expansion remain authoritative.
The former fixed orientation header, permanent legend, and generic drag instruction were removed. A compact
context caption appears only while a chapter is active and contains the direct whole-venture escape.

No new library, token family, layout mode, filter, setting, inspector, or founder-facing noun was introduced.
