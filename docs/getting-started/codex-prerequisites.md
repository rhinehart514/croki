# Codex prerequisites

- Install Codex CLI so `codex` is on your PATH.
- Authenticate Codex before running Croki (for example via API key or ChatGPT auth supported by Codex).
- Croki starts the server via `codex app-server` per session.

Codex is one supported provider, not a Croki runtime requirement. Claude,
Cursor, Grok Build, OpenCode, and OpenClaw can also back Threads when their
local prerequisites are ready.
