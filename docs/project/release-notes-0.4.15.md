# Croki 0.4.15 — Daily Work, Kept Moving

Croki 0.4.15 brings the current daily workspace forward without adding another
product mode or asking founders to manage more machinery.

## Product result

- Image attachments are safer, including automatic HEIC and HEIF conversion
  before upload.
- Threads can retain their linked pull request, and the sidebar follows that
  review through merge.
- Provider sessions recover more reliably after reconnects, interrupts, and
  upgrades.
- Long-running work causes less unnecessary rescanning and repainting.
- Croki's name, commands, themes, setup guidance, and failure messages now agree
  across web, desktop, mobile, server, and project configuration surfaces.
- Local pairing and triage discovery use the same `CROKI_HOME` selected by the
  development runner.

This release publishes the desktop builds. Package-registry, hosted web, relay,
and production mobile releases remain separate.
