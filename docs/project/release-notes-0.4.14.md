# Croki 0.4.14 — Fresh T3 Foundation

Status: source candidate
Date: August 21, 2026

Croki 0.4.14 rebuilds the product overlay on T3 Code commit `be7d35aa`. This is
a fresh foundation with the Croki product carried forward, not another sync
stacked onto the increasingly divergent 0.4.13 tree.

## Product result

- Current T3 workspace navigation, composer drawers, slash-command skill
  discovery, compact tool activity, theme handling, source-control behavior,
  and Preview performance now underpin Croki.
- Croki keeps its projects, Threads, checkpoints, Preview, terminals, files,
  providers, Thought Views, explicit application brief, and founder-facing
  Canvas projection.
- Codex turns retain the T3-derived host contract for collaboration mode and
  product-native Preview routing, with Croki runtime identity and no hidden
  task strategy or automatic application prompt.
- Web, desktop, server, contracts, shared runtime, and mobile now compile as one
  refreshed workspace. Provider-session recovery and current tool lifecycle
  behavior are retained across the Croki orchestration boundary.

## Compatibility and ownership

- Croki package names, app schemes, visible branding, state paths, schema route,
  and migration history remain Croki-owned.
- The pre-refresh source is preserved at
  `archive/pre-0.4.14-t3-refresh-2026-08-21` for audit and recovery.
- Release destinations still fail closed independently. Preparing this source
  candidate does not publish a GitHub release, npm package, relay, web build,
  signed desktop build, announcement, or mobile update.
