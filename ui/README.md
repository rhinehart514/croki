# Drover interface

The Electron interface implements the two-surface contract in [`../DESIGN.md`](../DESIGN.md).

## Work

Work is direct Claude/Codex conversation with exact Threads, Runs, coding attempts, files, diffs, preview,
terminal, verification, artifacts, evidence, and founder consequences. The transcript is primary; an exact
workbench appears only when exact material exists.

## Product / GTM

Product / GTM is one living venture canvas over the v3 semantic model. Current truth, provisional alternatives,
live work, outward actions, founder gates, and returned evidence remain visually distinct and causally joined.
Branch review supports exact deltas, conflict visibility, continuation, close, and selective founder merge.

The rail contains local search, compact agent pills, and connected capability pills. There is no Releases,
System, pipeline-lane, organization, or Heat surface. Product releases appear as one outward-action kind.

## Interface rules

- Near-black neutral room; DM Sans for operating text; mono only for machine material.
- Blue is action/focus; amber is founder authority; restrained texture marks provisional work.
- Nodes remain compact readable pills. Exact deltas, evidence, and decisions receive larger review space.
- Layout is presentation, never semantic truth.
- Agent-inferred changes remain provisional. Founder edits are immediate and undoable.
- Unsupported drops refuse visibly and persist nothing.
- No raw transport error is the primary recovery experience.
- Keyboard, 200% zoom, reduced motion, offline, dense data, and restart states are first-class.
