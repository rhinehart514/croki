# Croki launch brief

## Audience

Founders who build software with Codex, Claude Code, Cursor, Grok, or OpenCode and want one inspectable environment instead of fragmented agent sessions.

## Promise

Croki is a coding environment for founders. Threads preserve the work, optional repository-owned Canvas context preserves the product reasoning, and native T3 Code surfaces make agent execution observable and reversible.

## Story

1. Supported coding agents converge in one durable Croki Thread.
2. The founder request, repository, model, and current Canvas context stay visible.
3. A real agent result makes the release diff observable and attributable to the Thread.
4. Canvas preserves durable product intent, decisions, evidence, and consequences without becoming an execution system.
5. Croki is open source and designed for founders.

## Acceptance criteria

- 20 to 30 seconds.
- True black background and white primary text.
- No generated voice, avatar, stock footage, or fabricated product state.
- At least one deterministic capture of the running Croki product.
- Every product claim maps to repository evidence.
- Motion supports comprehension and never behaves as decorative ambient animation.
- The Lottie motion asset must complete an authenticated LottieLab edit/export round trip before final acceptance.
- Final 16:9 and 9:16 renders come from the same composition system.
